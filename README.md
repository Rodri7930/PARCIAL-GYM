Sistema de Membresías y Control de Acceso a Gimnasio

Descripción

Sistema desarrollado en Python para gestionar socios, planes de membresía, membresías, entrenadores y asistencias de un gimnasio.

Objetivo

Desarrollar un sistema organizado aplicando Programación Orientada a Objetos, arquitectura por capas, control de versiones con Git y GitHub y trabajo colaborativo mediante ramas y Pull Requests.

Tecnologías

Python 

Visual Studio Code

Git

GitHub

Sistema de Membresías y Control de Acceso a Gimnasio

Descripción

Sistema desarrollado en Python para gestionar socios, planes de membresía, membresías, entrenadores y asistencias de un gimnasio.

Objetivo

Desarrollar un sistema organizado aplicando Programación Orientada a Objetos, arquitectura por capas, control de versiones con Git y GitHub y trabajo colaborativo mediante ramas y Pull Requests.

Tecnologías

Python 

Visual Studio Code

Git

GitHub


Flujo de trabajo Git

El proyecto utiliza Git y GitHub para controlar versiones y trabajar de forma colaborativa.

Los cambios se realizan en ramas de funcionalidad y posteriormente se integran a la rama principal mediante Pull Requests.

Flujo utilizado:

- Actualizar la rama local.
- Crear una rama de funcionalidad.
- Realizar los cambios.
- Ejecutar las pruebas.
- Crear un commit.
- Subir la rama a GitHub.
- Crear un Pull Request.
- Revisar y aprobar los cambios.
- Integrar los cambios a main.
